# Excel Data Analysis & Interactive Dashboard

## Project Overview
This repository contains an end-to-end data analysis project developed in Microsoft Excel. The project covers the complete analytical lifecycle—from raw data ingestion and quality validation to multi-dimensional data modeling, advanced formula calculations, and interactive executive reporting.

---

## Key Objectives
- Clean, standardize, and validate raw transactional records.
- Uncover monthly sales trends, category performance, and regional revenue drivers.
- Provide decision-makers with dynamic, interactive KPI dashboards to track core business metrics.

---

## Analytical Workflow

### 1. Data Cleaning & Preparation
- **Missing Value & Duplicate Treatment:** Detected and resolved null values, erratic inputs, and duplicate transaction rows.
- **Data Validation & Formatting:** Standardized date formats, numeric currency fields, and categorized text attributes using Trim and Proper functions.
- **Lookup Architecture:** Integrated multi-table lookups using `XLOOKUP`, `INDEX/MATCH`, and structured table references.

### 2. Analysis & Modeling
- **Aggregations & Logic:** Applied conditional aggregations (`SUMIFS`, `COUNTIFS`, `AVERAGEIFS`) alongside nested logical statements (`IF`, `IFS`).
- **Pivot Summaries:** Built pivot tables to analyze sales by channel, regional distribution, and month-over-month (MoM) growth rates.

### 3. Interactive Dashboard
- **Dynamic Controls:** Added timeline filters and slicers linked across multiple pivot tables for real-time visual filtering.
- **Executive Visuals:** Designed clean bar charts, trend line charts, and donut charts equipped with dynamic data labels.
- **Conditional Formatting:** Applied custom rules and data bars to quickly highlight top/bottom performers and anomaly thresholds.

---

## Tools & Functions Used
- **Application:** Microsoft Excel
- **Core Functions:** `XLOOKUP`, `INDEX`, `MATCH`, `SUMIFS`, `COUNTIFS`, `DATEDIF`, `TEXT`
- **Features:** Pivot Tables & Pivot Charts, Dynamic Slicers, Data Validation, Conditional Formatting
